# example Output

You have the option of creating or editing entries in the public blackboard.
Create new ones for elements that you need to complete the goal, and edit only the entries that you are assigned to work on.
When creating new entries, make sure to add a proper contribution but in the todos mention "let an expert fill in details". never try to make up guids, they are generated by the system later, or should be retrieved by tools.

Since you cannot update or read other private blackboards, you can only update your own private blackboard. You are also free to add discussion points in the private blackboard to clarify your thoughts.

{
    "public_blackboard_updates": [
        "Element":    
            {    
            "name" : "name-of-entry-to-update-or-add"
            "Type" : "ElementType(UseParentClassHere)",   
            "Contribution" : "this elements provides xyz towards the goal and is linked to other elements abc",
            "TODOs" : ["establish link to abc", "another todo"] 
            },
    ],
    "private_blackboard_update": {
        "Discussion": "entry_value",
        "ObjectData" : {example_object_data}
    }
}

It is also allowed to return an empty list for public_blackboard_updates if you dont need to add anything there.
